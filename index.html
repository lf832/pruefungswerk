STARTKLAR MACHEN

Prüfungen hinzufügen

Wählt eine JSON-Datei im Format der Vorlage. Für jede Aufgabe könnt ihr Fragetyp, Antwortoptionen, richtige Lösung und Erklärung hinterlegen.

{
  "examId": "ihk-2025-01",
  "title": "Abschlussprüfung – Teil 1",
  "year": 2025,
  "questions": [{
    "id": "aufgabe-1",
    "type": "single",
    "prompt": "Fragetext …",
    "points": 2,
    "options": [
      {"id":"a", "text":"Antwort A"},
      {"id":"b", "text":"Antwort B"}
    ],
    "answerIds": ["b"],
    "solution": "Begründung / Lösung …"
  }]
}

Fragetypen: single (eine Auswahl), multiple (mehrere), text (Freitext mit Selbstbewertung). Nutzt ausschließlich eure eigenen Unterlagen bzw. Materialien, die ihr verwenden dürft.
